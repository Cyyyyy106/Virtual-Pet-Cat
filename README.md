Virtual Pet Cat 

This is a terminal-based virtual cat game built with Python. The user can feed, play, or let the cat sleep. The pet has three status bars—hunger, energy, and happiness—and its mood changes depending on its condition.

Features
Play to earn coins, feed to spend coins
ASCII cat face and mood system
Text-based input/output in terminal
Pet levels up when happiness reaches 10
Status is saved to a local file


Make sure you have Python installed. Run the following in terminal:

```bash
python3 virtualpet.py
