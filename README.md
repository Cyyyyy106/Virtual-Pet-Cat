Virtual Pet Cat 

This is a terminal-based virtual cat game written in Python. You can feed, play, clean, talk, let your pet sleep, or send it on an adventure. The pet has three main stats—hunger, energy, and happiness—and its mood changes based on how well you care for it.

Features
Six actions: Feed, Play, Sleep, Clean, Talk, Adventure
Earn coins by playing and exploring
Random weather and surprise events
Pet levels up when happiness reaches 10
Game state saved in a local text file

Make sure you have Python installed. Run the following in terminal:

```bash
python3 virtualpet.py
